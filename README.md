# eiken

英検（実用英語技能検定）の公式サイトで公開されている過去問を、まとめてダウンロードする Python スクリプトです。

ダウンロード対象:

- 問題冊子（PDF）
- リスニング原稿（PDF）
- 解答（PDF）
- リスニング音声（mp3）

## 必要環境

- Python 3.8 以上
- 標準ライブラリのみ使用（`pip install` は不要です）

## 使い方

```bash
# 全級をダウンロード
python3 eiken_download.py

# 指定した級だけダウンロード
python3 eiken_download.py 2

# 複数の級を指定
python3 eiken_download.py 1 pre1 pre2plus

# 保存先を指定
python3 eiken_download.py -o ~/eiken

# ダウンロードせず、対象ファイルの一覧だけ表示
python3 eiken_download.py --list
```

### 級の指定

| 引数 | 級 |
| --- | --- |
| `1` | 1級 |
| `pre1` | 準1級 |
| `2` | 2級 |
| `pre2plus` | 準2級プラス |
| `pre2` | 準2級 |
| `3` | 3級 |
| `4` | 4級 |
| `5` | 5級 |

`p1`、`p2`、`p2plus` も、それぞれ `pre1`、`pre2`、`pre2plus` の別名として使えます。
引数を省略すると、全級が対象になります。

### オプション

| オプション | 説明 |
| --- | --- |
| `-o`, `--output` | 保存先ディレクトリ（既定値: `./eiken_past_papers`） |
| `--list` | ファイルの一覧のみ表示し、ダウンロードしない |
| `-h`, `--help` | ヘルプを表示 |

## 保存先のフォルダ構成

級ごと、回ごとにフォルダを分けて保存します。ファイル名は公式サイトのものをそのまま使います。

```
eiken_past_papers/
├── 1級/
│   ├── 2026年度第1回/
│   │   ├── 2026-1-1ji-1kyu.pdf          # 問題冊子
│   │   ├── 2026-1-1ji_1kyuscript.pdf    # リスニング原稿
│   │   ├── 202601F1kyu.pdf              # 解答
│   │   ├── 1Q-part1.mp3                 # リスニング音声
│   │   └── ...
│   ├── 2025年度第3回/
│   └── 2025年度第2回/
├── 準1級/
├── 2級/
└── ...
```

## 定期的に実行する

すでにダウンロード済みのファイルはスキップされるため、繰り返し実行しても問題ありません。
公式サイトに新しい回が追加されたときは、再実行すると新しい分だけが追加されます。
cron や launchd に登録すれば、自動で更新できます。

ダウンロード中のファイルは `.part` という一時ファイルに書き込み、完了してから正式な名前に変更します。
そのため、途中で中断しても不完全なファイルは残りません。

## 注意事項

- 公式サイトに掲載されているのは、直近 3 回分（約 1 年分）の一次試験のみです。それより前の回や、二次試験（面接）の資料は取得できません。
- 本会場・準会場 F 日程（2〜5級のみ）で実施された分だけが公開されています。
- サーバーへの負荷を抑えるため、リクエストの間隔を 1 秒空けています。
- 公式サイトの構成が変わった場合、ファイルを取得できなくなることがあります。その際はエラーメッセージが表示されます。
- ダウンロードしたファイルの著作権は日本英語検定協会にあります。私的な学習の範囲でご利用ください。
